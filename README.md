# MarranoFTP-Amiga
A very marrano FTP (0.66) client for the Amiga Platform (AROS/MorphOS) developed in 2006-2008 with AmiDevCPP.

# MarranoFTP Plus

A bugfixed and improved version with Claude AI, finally 1.0, with separate versions for AmigaOS 1.3 and AmigaOS 2.0+.

Works on:

* Workbench 1.3
* Workbench >2.0

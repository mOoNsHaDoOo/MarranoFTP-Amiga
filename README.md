# MarranoFTP Plus

A bugfixed and improved (with Claude AI) very marrano FTP, finally 1.0, with separate versions for AmigaOS 1.3 and AmigaOS 2.0+.

Works on:

* Workbench 1.3
* Workbench >2.0

Needs fixes and testing on:

* AROS
* MorphOS

Original version worked on AROS and MorphOS only while new version compiles with SAS/C and is targeted mainly for 68K amigas.
